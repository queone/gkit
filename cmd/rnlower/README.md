## rnlower
Rename every file in the current directory to lowercase.

### Why
Lowercases every file name in a directory in one step instead of renaming each file by hand.

### Usage

```text
rnlower v2.2.0
Rename every file in the current directory to lowercase
github.com/queone/gkit/tree/main/cmd/rnlower

Usage
  rnlower  Ask for confirmation, then rename every file in the current directory

Options
  -v, --version   Print rnlower v2.2.0 and exit
  -h, -?, --help  Show this help and exit
```

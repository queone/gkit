## brew-update
Update, upgrade, and clean up Homebrew formulae and casks.

### Why
Runs Homebrew's update, upgrade, and cleanup steps for formulae and casks as one command instead of several.

### Usage

```text
brew-update v1.5.0
Update, upgrade, and clean up Homebrew formulae and casks
github.com/queone/gkit/tree/main/cmd/brew-update

Usage
  brew-update  Run brew update, brew upgrade, cask upgrades, and brew cleanup -s

Options
  -v, --version   Print brew-update v1.5.0 and exit
  -h, -?, --help  Show this help and exit
```

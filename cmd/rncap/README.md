## rncap
Capitalize every word of every file name in the current directory.

### Why
Capitalizes every file name in a directory in one step instead of renaming each file by hand.

### Usage

```text
rncap v2.2.0
Capitalize every word of every file name in the current directory
github.com/queone/gkit/tree/main/cmd/rncap

Usage
  rncap  Ask for confirmation, then rename every file in the current directory

Options
  -v, --version   Print rncap v2.2.0 and exit
  -h, -?, --help  Show this help and exit
```
